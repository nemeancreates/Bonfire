# Bonfire (WoW: Forever addon)

- Target: WoW: Forever beta client 1.60.1, `## Interface: 16001`. Mainline 12.x addon API with Midnight restrictions; Lua 5.1.
- Client: `C:\Program Files (x86)\World of Warcraft\_classic_beta_` (product `wow_classic_beta` is the Forever beta). `Interface\AddOns\Bonfire` is a junction to this repo, so edits go live on `/reload`.
- `Libs\` is generated by `scripts\setup.ps1` (gitignored). Keep `setup.ps1`, `embeds.xml` and `.pkgmeta` in sync when adding a library. `.pkgmeta` (BigWigs packager) is untested.
- Before finishing a change: `scripts\lint.ps1` (0 warnings), `scripts\test.ps1` and `scripts\tablesim.ps1` (plays the real `Table.lua` against a fake clock) must pass; then `scripts\package.ps1` builds `dist\Bonfire-x.y.z.zip`. Bump `## Version` in `Bonfire.toc` each round. Run the scripts with the PowerShell tool. `scripts\sim.ps1` simulates Odd Man Out.
- Pure logic (no WoW API) lives in files `tests\run.lua` loads: `Roll`, `Money`, `Ledger`, `History`, `Bets`, `Reputation`, `Quips` (mostly), `Games\*`. Keep them pure; money math belongs in `Ledger.lua` with tests.
- New `.lua` files need a full game restart (edits only need `/reload`); add them to `Bonfire.toc` and, if pure, to the test load lists.
- Register game events with `ns.OnEvent`, never `Bonfire:RegisterEvent`: AceEvent keeps one handler per event, so a second registration silently replaces the first (a test enforces this).
- Comms: every message is sealed with a checksum (`Comm.Seal`); anything that fails it is dropped. The game throttles channel traffic and drops pieces of long messages, so the table state only goes through `Comm:SendLatest` (one in flight, newest wins, resent if a piece is lost), only when real players are seated, and carries the side-bet card only when it changed. Don't `Broadcast` anything large or frequent.
- The main window redraws often. Show its buttons with `Use(...)` in `UI.lua`, never `:Hide()` then `:Show()` in the same redraw: a button hidden between mouse down and up loses the click.
- Money is integer copper everywhere. Stake 0 = For fun table. The host's own gold never enters the ledger.
- File pattern: `local ADDON, ns = ...`; `ns.Bonfire` is the AceAddon object; slash subcommands register with `ns.AddCommand`.
- Wire names are "Name-Realm" as comms report them, which in Forever can include a surname ("Firstname Surname-Realm") while `UnitName` returns only "Firstname". `ns.Me()` is the name learned from our own channel echo; compare names from other APIs (roll lines, unit tokens, trade partners) with `ns.NameKey`. Comm prefix `Bonfire1`, discovery channel `BonfireCamp`.
- Not every retail global exists in Forever (`GetCoinTextureString` doesn't). Add new API calls to `/bf api` in `Debug.lua`.
- LF line endings, tabs in Lua/XML/TOC.
- Never use `/camp` as a command; it's Blizzard's logout.
- Open beta questions and answers: `docs/BETA-NOTES.md`. Design brief: `docs/CONCEPT.md`. Two-player script: `docs/TEST-PLAN.md`. Honest Broker (host reputation, built in 0.6.6): `docs/HONEST-BROKER.md`. Race/class quip proposals awaiting the user: `docs/QUIP-LINES.md`.
- Practice without a second player: `/bf dummy N` seats pretend players, `/bf bets demo` fills a betting card.
- Don't push to GitHub unless asked.
